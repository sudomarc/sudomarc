# Public Projects

A concise index of selected repositories.

## Featured

- **[Handshake](https://github.com/sudomarc/handshake)** — Android-first prototype exploring trusted-contact verification and advisory checks for high-pressure messages. It is not a voice-cloning detector, and the current Android release does not receive remote audio from carrier calls or WhatsApp.
- **[NETWATCH](https://github.com/sudomarc/NETWATCH)** — Linux-only Bash toolkit for authorized network discovery and controlled IPv4/IPv6 gateway administration, with dry-run support and ownership-aware firewall handling.
- **[OpenDroid website fork](https://github.com/sudomarc/opendroid)** — Website and landing-page work for the upstream OpenDroid project; this fork is not the Android application source.
- **[Carbone Blog](https://github.com/sudomarc/carbone-blog)** — Lightweight HTML blog project.

Project capabilities and limitations are documented in each repository.
